# Voltix Mobile

## Project Overview
Voltix Mobile is a simple online mobile accessories website. The website provides customers with information about affordable and reliable mobile accessories such as chargers, wireless earbuds and phone cases.

## Website Pages
- **Home** - Introduction to Voltix Mobile and featured products.
- **About Us** - Information about the business, mission and vision.
- **Products** - Displays available mobile accessories, prices and Add to Cart buttons.
- **Contact Us** - Allows customers to enter their name, email address and message.

## Technologies Used
- HTML5
- CSS3

## CSS Features
The website uses:
- External CSS
- Flexbox for layout
- Responsive design
- Media queries for tablet and mobile screens
- Relative units such as `rem` and `%`
- Consistent colours, typography, spacing and sizing
- Hover, focus and active states
- Responsive images
- Borders, border-radius and box shadows

## Responsive Design
The website is designed to work across:
- Desktop screens
- Tablet screens
- Mobile screens

The navigation, logo, content and product sections adjust to smaller screen sizes using CSS media queries.
